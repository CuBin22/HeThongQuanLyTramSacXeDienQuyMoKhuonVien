# HeThongQuanLyTramSacXeDienQuyMoKhuonVien
Hệ thống phải đặt phiên, phân bố cổng, theo dõi trạng thái, tính phí giả lập và sự cố. Phân tích yêu cầu, mô hình hóa miền, phân bố trách nhiệm cho lớp/ đối tượng, thiết kế kiến trúc, kiểm thử và triển khai. Điểm nhấn là idempotency lệnh, an toàn thiết bị và không xử lý thanh toán thật. Jave/.Net; MQTT; PostgreSQL; React; Docker; OpenTelemetry
